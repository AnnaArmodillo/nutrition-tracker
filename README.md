# Трекер питания

Приложение для контроля дневного КБЖУ.

## Функционал
- Добавление продуктов
- Запись потребления по датам
- Визуализация нутриентов (графики, диаграммы)
- Сохранение данных в Local Storage

## Стек
- Vue 3
- Pinia
- Tailwind CSS
- Vue Test Utils

## Запуск
npm install
npm run dev
