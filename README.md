# Трекер питания

Приложение для контроля дневного КБЖУ.

## Функционал
- Добавление продуктов
- Запись потребления по датам
- Визуализация нутриентов (графики, диаграммы)
- Сохранение данных в Local Storage

## Стек
- Vue 3
- Pinia
- Tailwind CSS
- Vue Test Utils

## Запуск
npm install
npm run dev

## Демо-данные

При первом запуске можно загрузить демо-данные за 3 дня:
- День 1 — потребление в пределах нормы
- День 2 — превышение нормы
- День 3 — недобор нормы

Это позволяет сразу увидеть, как работают графики и расчёты, без ручного ввода.
